# Roadmap de Musnim

| Hito | Objetivo | Criterio de aceptación |
| --- | --- | --- |
| M0 | Fork, extensión aislada, pruebas y primer PR | Código en GitHub; CI Python Windows/macOS/Linux |
| M1 | Grabado LilyPond SVG real en Manim | SVG importado, etiquetas validadas, MP4 de prueba |
| M2 | Strauss: análisis crítico de cc. 1–21 | Matriz compás/instrumento/altura/acorde y fuentes |
| M3 | Animación semántica de partituras | Selección, color y movimiento individual de notas |
| M4 | Sincronización audiovisual | Timestamps comprobados contra audio permitido |
| M5 | Primera película 1080p | Render reproducible, revisión musicológica y QA |

La salida M0 comprende pruebas unitarias Python; se considerará
terminado tras verificarse la CI remota. Las pruebas de audio,
grabado real y render se incorporarán progresivamente.

La primera película distingue tres ámbitos: relaciones matemáticas,
descripción de los fenómenos musicales y hermenéutica simbólica.
